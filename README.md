# 📋 فرم گزارش هفتگی کارآموزی

یک **فرم اداری کامل** برای ثبت و چاپ گزارش هفتگی دوره کارآموزی — با تقویم جلالی، امضای دیجیتال، مدیریت چند هفته و خروجی PDF تمیز در قطع A4.

کل برنامه **یک فایل HTML** است: بدون سرور، بدون نصب، بدون اینترنت. فونت وزیرمتن هم داخل خود فایل جاسازی شده تا روی هر دستگاهی دقیقاً یکسان دیده شود.

## 🖨️ تنظیمات چاپ (مهم)

هنگام گرفتن PDF این موارد را رعایت کنید تا خروجی دقیقاً دو صفحه و تمیز شود:

| تنظیم | مقدار درست |
|---|---|
| مقصد (Destination) | **Save as PDF** |
| اندازه کاغذ (Paper size) | **A4** |
| جهت (Layout) | **عمودی / Portrait** |
| حاشیه (Margins) | **Default** — روی None یا Custom نگذارید |
| Background graphics | ✅ **تیک بزنید** |
| Headers and footers | ❌ **تیک را بردارید** |
| مقیاس (Scale) | **Default / 100%** |

> اگر خروجی سه صفحه شد، یعنی یکی از موارد بالا رعایت نشده است.

## 📱 انتقال اطلاعات از لپ‌تاپ به گوشی

اطلاعات در حافظه‌ی همان مرورگر ذخیره می‌شود و خودبه‌خود بین دستگاه‌ها منتقل نمی‌شود. برای انتقال:

1. روی لپ‌تاپ دکمه‌ی **«⬇️ خروجی JSON»** را بزنید
2. فایل دانلودشده را با تلگرام، ایمیل یا کابل به گوشی بفرستید
3. در گوشی همین صفحه را باز کنید و **«⬆️ بارگذاری JSON»** را بزنید

تمام اطلاعات شامل امضاها منتقل می‌شود. اگر بیش از یک هفته داشته باشید، موقع خروجی از شما می‌پرسد همه‌ی هفته‌ها را می‌خواهید یا فقط هفته‌ی جاری را.
